## Prerequisites

- **Go 1.26.1 or higher** — required for `go install` and for building from source. Not needed if you download a prebuilt binary.
- **A GitHub Personal Access Token** — fine-grained (recommended) or classic. See [Authentication](authentication.md).

## Option 1: Go install

The shortest path if you already have Go:

```bash
go install github.com/pradyb/sgh-cli@latest
```

This installs the binary as `sgh-cli` into `$(go env GOPATH)/bin`. Make sure that directory is on your `PATH`. Most of this documentation calls the tool `sgh`, so you may want to rename or symlink it:

```bash
# Linux/macOS
ln -s "$(go env GOPATH)/bin/sgh-cli" "$(go env GOPATH)/bin/sgh"
```

## Option 2: Prebuilt binary

Every tagged release attaches prebuilt binaries built with `CGO_ENABLED=0`, so they have no runtime dependencies. Download the one for your platform from the [releases page](https://github.com/pradyb/sgh-cli/releases):

| Platform | Asset |
|---|---|
| Linux (x86-64) | `sgh-linux-amd64` |
| Linux (ARM64) | `sgh-linux-arm64` |
| macOS (Intel) | `sgh-darwin-amd64` |
| macOS (Apple Silicon) | `sgh-darwin-arm64` |
| Windows (x86-64) | `sgh-windows-amd64.exe` |

Each release also publishes `checksums.txt`. Verify before running:

```bash
# Linux/macOS
curl -LO https://github.com/pradyb/sgh-cli/releases/latest/download/sgh-linux-amd64
curl -LO https://github.com/pradyb/sgh-cli/releases/latest/download/checksums.txt
sha256sum --check --ignore-missing checksums.txt

chmod +x sgh-linux-amd64
sudo mv sgh-linux-amd64 /usr/local/bin/sgh
```

On Windows, rename `sgh-windows-amd64.exe` to `sgh.exe` and place it in a directory on your `PATH`.

## Option 3: From source

Useful if you want to build a specific branch or make local changes:

```bash
git clone https://github.com/pradyb/sgh-cli.git
cd sgh-cli
go build -o sgh .

# Linux/macOS — put it on your PATH
sudo mv sgh /usr/local/bin/

# Windows — move sgh.exe to a directory on your PATH
```

## Verify the installation

```bash
sgh --help
sgh version
```

`sgh version` prints the version string, commit SHA, and build date. Binaries built from source without release ldflags report `dev` as the version — that is expected.

To confirm your token and network path work end to end:

```bash
sgh health
```

## Shell completion

Completion scripts are generated by the binary itself and cover Bash, Zsh, Fish, and PowerShell:

```bash
# Bash
sgh completion bash > /etc/bash_completion.d/sgh

# Zsh
sgh completion zsh > "${fpath[1]}/_sgh"

# Fish
sgh completion fish > ~/.config/fish/completions/sgh.fish

# PowerShell
sgh completion powershell | Out-String | Invoke-Expression
```

Once installed, two flags complete from your own configuration:

- `--org` / `-o` — tab-completes organization names from your config file
- `--repository` / `-r` — tab-completes repository names for the selected org
